Servidor do catálogo (recomendado)

Para salvar jogos de verdade, editar/excluir de qualquer navegador e calcular SHA-256 mesmo com bloqueio do Drive, rode node server.mjs no seu host. O servidor guarda o catálogo em data/catalog.json e publica /feed.ini para a dash.

Publicar no GitHub Pages (opcional)

Use esta opção se quiser um site estático. O token fica salvo apenas neste navegador e só é necessário para publicar.

Atualizar a loja

A dashboard lê o feed.ini publicado. Ao abrir o menu da loja na dash, ela atualiza automaticamente. Gere o store-site.ini para apontar o Xbox para este feed.
